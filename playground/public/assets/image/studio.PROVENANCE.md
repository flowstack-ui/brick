# Studio example image

`studio.webp` is a 768 × 512 export of an original FLOWSTACK image generated
with OpenAI image generation on September 2, 2026. It depicts a fictional
sunlit creative studio, not an actual workplace. The image has no known person,
third-party mark, text, or watermark. It is reused here as local demonstration
media for the Aspect Ratio documentation example.

`studio-384.webp` is a 384 × 256 downsample of the same original, used as a
real smaller responsive source candidate for Image documentation.
