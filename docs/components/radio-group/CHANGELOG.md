# Radio Group changelog

Radio Group follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Resolve label sizes and leading through shared semantic typography while preserving the existing size scale.

- Align trailing marks in intrinsic vertical label-first groups and correct custom artwork and density-example alignment.

- Added responsive xs/sm/md/lg sizes, solid/outline/subtle variants, semantic
  tones, density, logical label placement and responsive option spacing.
- Added native open item parts, controller/provider and public contexts while
  preserving the closed Item button ref.
- Aligned default md to a 20px solid mark; removed compulsory row highlights and
  invalid side stripes. Documented the outline migration and retired CSS hooks.
- Recovered enabled keyboard entry and required validity for unavailable values.

## 0.1.10

### Added

- Added public Agent Knowledge for single-choice selection, accessible group
  and option naming, roving focus, read-only and form behavior, responsive
  validation, and the exact installed Atom RadioGroup reference.
- Initial Atom-backed Root and Item compound component with three sizes,
  vertical/horizontal layout, built-in circular visual, complete state paint,
  native form/validation behavior, read-only selection lock, RTL, composition,
  and stable customization hooks.
