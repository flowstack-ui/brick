# QrCode changelog

QrCode follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Add responsive sizes, presentation defaults, graphic unstyled, host composition
  and scoped IDs. Preserve ref cleanup and root-scoped overlay customization.
- Use finished text/IconButton download actions, group defaults and loading/focus.
- Add copyable feature examples and API/TOC; retain qualification scenarios.

- Add shared token-only radius selection to the boundary parts documented in the Radius guide; preserve omitted defaults and independent internal geometry.

### Fixed

- Match one-third-width square logo overlays, prevent text from stretching the
  backing, and preserve readable inherited ink for authored logo text.

### Added

- Add Atom-backed local QR display, named sizes, safe scanning paint, logo overlays
  and consistent generated-image download actions.
