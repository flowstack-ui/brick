# Alert changelog

Alert follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Use semantic label weight for titles without changing the default metrics.

### Changed

- Align compact line heights, inset border geometry, inline spacing and inherited indicator sizes.
- Support responsive size, variant, inline and alignment, shared radius, logical accent stripes and neutral content foreground.
- Support Indicator host composition and document every part with executable examples.

### Added

- Composable inline feedback with five statuses, four recipes, three sizes and custom indicators.
