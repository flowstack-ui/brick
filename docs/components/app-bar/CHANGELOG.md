# AppBar changelog

## Unreleased — 0.1.0

- Added the Atom-backed Root, Toolbar, Start, Center, and End namespace.
- Added four positions, three surfaces, two densities, separator, elevation,
  blur, logical RTL layout, forced-colors, and server-safe presentation.
- Added neutral and accent tones across every surface variant, geometrically
  centered content, and public component tokens for custom brand treatments.
- Exported `AppBarTone` from the package root as well as the AppBar subpath.
- Added independent controlled playground and browser evidence for defaults,
  recipes, density, effects, positions, composition, customization,
  preferences, constrained layout, and RTL.
