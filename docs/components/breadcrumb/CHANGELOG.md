# Breadcrumb changelog

Breadcrumb follows the package version of `@flowstack-ui/brick`.

## Unreleased

### Changed

- Use shared compact navigation typography at every breakpoint and restore
  the documented 24px line height for the large size.

- Narrow navigation tones to neutral, accent and inherit; restore accent hover
  feedback and inherited-color interaction underlines.
- Normalize numeric spacing in the closed recipe and use For in collection examples.

- Add breadcrumb-styled Trigger, responsive sizes/variants and semantic tones.
- Ship icon gaps, directional separators, linked-current focus and token overrides.
- Change default geometry and plain decoration; subtle preserves the old interaction underline.
- Add real menu/router/closed-wrapper examples and preserve native landmark labels.

### Added

- Added public Agent Knowledge for component selection, composition,
  CSS-delivery, recurring mistakes, and validation.

- Added the complete Atom-backed eight-part hierarchy trail with three sizes,
  plain, underline and subtle ancestor-link recipes, current-page styling, custom
  separators, Ellipsis composition, responsive wrapping, and public CSS hooks.
