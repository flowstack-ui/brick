# Feed changelog

Feed follows the package version of `@flowstack-ui/brick`.

## Unreleased

### Added

- Added `dividerStrength="default"` for compact feeds that need a clearer
  semantic row boundary while preserving the subtle default.

- Added public human- and machine-readable Agent Knowledge for choosing Feed
  only for dynamic rich article streams, composing bounded Scroll Area
  ownership, and avoiding passive-tray live-region announcements.
- Added the Atom-backed two-part Feed with plain, divided, and outline
  variants; compact and comfortable density; direct rich article composition;
  visible keyboard positioning; responsive RTL; preference support; and public
  CSS customization variables.
