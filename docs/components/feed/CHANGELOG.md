# Feed changelog

Feed follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Clarify logical-start action alignment: prefer outline Buttons beside prose,
  preserving normal padding and reserving ghost for intentional contextual actions.

- Add responsive variant, density and divider strength, named parts and styling
  PropsProvider. Preserve inherited token overrides and omit leading separators
  when earlier articles are hidden. Rebuild the source-paired documentation page.

- Add shared token-only radius selection to the boundary parts documented in the Radius guide; preserve omitted defaults and independent internal geometry.

## 0.1.10

### Added

- Added `dividerStrength="default"` for compact feeds that need a clearer
  semantic row boundary while preserving the subtle default.

- Added public human- and machine-readable Agent Knowledge for choosing Feed
  only for dynamic rich article streams, composing bounded Scroll Area
  ownership, and avoiding passive-tray live-region announcements.
- Expanded Feed Agent Knowledge with its exact Atom authority and stable
  logical-position and mounted-focus requirements for paged or windowed feeds.
- Added the Atom-backed two-part Feed with plain, divided, and outline
  variants; compact and comfortable density; direct rich article composition;
  visible keyboard positioning; responsive RTL; preference support; and public
  CSS customization variables.
