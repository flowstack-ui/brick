# Tree changelog

Tree follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Align independent-disclosure and checking examples by deriving child indentation from the public trigger-size and row-gap tokens.

- Correct modifier-based multiple selection through Atom; Shift-navigation extends the visible range.
- Remove redundant chevrons from file examples, align opt-in guides with artwork, and demonstrate unindented composition separately.
- Keep solid checked/mixed checkbox paint independent of row selection and preserve disabled/forced-color treatment.

- Document decorative file and expansion-aware folder artwork independently of disclosure arrows.

- Use the shared focus-width token and document optional application-owned TanStack windowing.

- Add independent disclosure and checking, public collection/controller exports, opt-in interactive rows, async loading feedback and measured group motion through Atom.
- Add responsive xs/sm/md sizes, independent density, neutral/accent tones, subtle/solid selection, unlimited depth and full-row state paint.
- Rebuild source-paired documentation examples and cover form submission, nonselectable branches, checking, lazy retry and rename recovery.

- Limit pointer hover paint to the pointed ItemContent, excluding ancestor and disabled rows.

- Use canonical focus-width tokens while preserving existing focus ownership and compact placement.

- Add shared token-only radius selection to the boundary parts documented in the Radius guide; preserve omitted defaults and independent internal geometry.

- Added semantic border tones shared by the outline boundary and optional
  hierarchy guides.

## 0.1.10

- Added public Tree Agent Knowledge covering hierarchical selection, required
