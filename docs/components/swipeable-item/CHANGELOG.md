## 0.1.10

### Added

- Added public SwipeableItem Agent Knowledge covering enhancement-only
  selection, labelled action panels, gesture and keyboard ownership, the
  no-full-swipe execution boundary, explicit alternatives, and validation.
- Added the Atom-backed Root, Content, and Actions family with plain and
  outline recipes, logical action panels, rounded containment, required
  localized labels, preference support, and a visible non-drag action path.
