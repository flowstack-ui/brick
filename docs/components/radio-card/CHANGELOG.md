# RadioCard changelog

RadioCard follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Resolve label sizes and leading through shared semantic typography while preserving the existing size scale.

- Add shared token-only radius selection to the boundary parts documented in the Radius guide; preserve omitted defaults and independent internal geometry.

### Added

- Added the Atom-backed Radio Card compound component with rich card content,
  optional indicator and addon, three sizes, four variants, logical alignment,
  complete radio/form behavior, state paint, forced colors, dark appearance,
  public CSS hooks, Agent Knowledge, and independent qualification evidence.

### Changed

- Aligned the default horizontal Control anatomy, orientation-aware layout,
  medium-weight labels, size geometry, and solid checked radio mark with the
  maintained rich-selection reference.
### Changed

- Breaking: Item is a label; compose one HiddenInput and move input refs to it.
- Added Label, RootProvider, Context, ItemContext and controller access.
- Added responsive recipes, independent contentOrientation and shared form tones.
- Corrected variant-specific selected borders, shadows, disabled and invalid paint.
- Rebuilt focused examples and multipart props documentation.
