# Scroll Area changelog

Scroll Area follows the package version of `@flowstack-ui/brick`.

## Unreleased

## 0.2.1 - 2026-08-31

### Fixed

- Made Root establish a shrinking grid viewport and clip only its outer box so
  a consumer-provided maximum size produces real Viewport overflow and native
  scrolling instead of escaped content.

### Added

- Added public Agent Knowledge for component selection, composition,
  CSS-delivery, recurring mistakes, and validation.

- Added Atom-backed Root and Viewport anatomy.
- Added vertical, horizontal, and both-axis native overflow.
- Added auto, always, and interaction visibility plus stable gutter.
- Added semantic scrollbar variables, focus, composition, and evidence.
