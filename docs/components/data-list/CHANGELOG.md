# Data List changelog

Data List follows the package version of `@flowstack-ui/brick`.

## Unreleased

### Changed

- Resolve compact text leading from semantic typography recipes at every
  breakpoint, preserving the existing 12/16, 14/20 and 16/24px geometry.

- Aligned sm/md/lg text and rhythm with compact metadata recipes; added responsive subtle/bold emphasis, size and label measures plus PropsProvider defaults.
- Fixed responsive orientation reversal, long-content overflow, grouped term/value placement and label-size token precedence. Horizontal auto now uses a consistent bounded measure.
- Added label/value paint and spacing tokens, rich label alignment, focused source-paired examples and full Props/TOC documentation.

### Added

- Added native Root, Item, Label, and Value anatomy with responsive
  orientation, three sizes, optional separators, and label measures.
