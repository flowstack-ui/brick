# Editable changelog


## Unreleased

Disabled presentation preserves the selected recipe and fades once to 50%, with a not-allowed cursor on the disabled hit target. Keep read-only separate; do not add an opacity wrapper around an already disabled control. Forced colors uses system disabled colors.

Editable follows the package version of `@flowstack-ui/brick`.

Public component: `Editable`.

### Added

- Add shared responsive typography, weight, tone, alignment, radius and inherited
  text presentation. Preview and editor use the same typography.
- Add structural projection, unstyled action composition and optional
  preview hover feedback. Refine compact size geometry.

- Add inline preview/edit composition, Atom-owned transactions, form/focus
  integration, multiline autoresize and three coordinated visual sizes.
