# Steps changelog

Steps follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Add external controllers, Number and Status composition helpers, responsive recipes and finite radius props.
- Refine subtle state paint and remove forced sibling widths and trigger hover fill.

- Use canonical focus width and the shared outside offset.

### Fixed

- Vertical progress and content share a row and wrap intrinsically in narrow
  hosts, rather than forcing content below the progress list.

### Added

- Added Atom-backed workflow Steps, solid/subtle recipes, four marker sizes, semantic tones, localized numbers, and completed Checkmarks.
### Changed

- Typography follows size-selected semantic recipes while preserving marker
  sizes and state behavior.
