# Spinner changelog

Spinner follows the package version of `@flowstack-ui/brick`.

## Unreleased

### Added

- Responsive sizes and passive artwork projection with `asChild`.
- Documentation examples for custom artwork and contained loading overlays.
- Public theme-aware visual loading indicator with sizes, tones, emphasis, ring thickness and CSS customization.
- Decorative and explicitly named graphic modes, reduced-motion and forced-color support.

### Changed

- Mirror the ring's starting arc in RTL while keeping clockwise motion.
- Keep empty names decorative and prevent authored runtime tab stops.
