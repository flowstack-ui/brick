# Tree Grid changelog

Tree Grid follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Resolve pointer cells before initial native focus through Atom, preventing the top-left focus flash.
- Use folder/file artwork without redundant disclosure slots in file-browser examples; keep independent disclosure as an explicit composition.

- Use the shared focus-width token and document optional application-owned TanStack windowing.

- Add independent disclosure, interactive cells and headers, public column resize handles and logical sticky columns.
- Add responsive size/density/variant, neutral/accent selection and authored minimum width; correct visible-row striping and depth metadata.
- Rebuild source-paired documentation with controlled selection, checkbox cells, editing, resizing, filtering and server-page recovery.

- Add shared token-only radius selection to the boundary parts documented in the Radius guide; preserve omitted defaults and independent internal geometry.

- Added Atom-backed `ColumnGroup` and `Column` parts with native `htmlWidth`
  sizing hints.
- Added transparent/base surfaces, semantic border tones, independent column
  borders, auto/fixed layout, vertical alignment, striping, and sticky headers.
- Preserved hierarchy selection over hover and hover over stripe paint.

## 0.1.10

### Added

- Added public TreeGrid Agent Knowledge covering hierarchy and coordinate
  relationships, active-cell navigation, expansion and row selection,
  application-owned actions and virtualization, overflow, and validation.
- Added the twelve-part Atom-backed Tree Grid with hierarchy, active-cell,
  expansion, selection, controlled sortable headers, line and outline recipes,
  sizing and density, logical alignment, responsive containment, RTL,
  decorative indicators, public tokens, and complete evidence ownership.
