# Locale Provider changelog

Locale Provider follows the package version of `@flowstack-ui/brick`.

## Unreleased

- Complete locale-aware API guidance and modern source-paired documentation examples.
- Export locale-aware useFilter with explicit overrides and inherited context.

### Added

- Added inherited `showPassword` and `hidePassword` action labels for Password Toggle Field, with explicit Root labels retaining precedence.

- Added inherited date action, validation and range-endpoint labels for Calendar, DateInput and DatePicker compositions.

- Added locale, logical direction, and overridable Brick-owned accessibility text inheritance without adding a DOM wrapper or application translation runtime.
