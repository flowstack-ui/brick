# Center changelog

Center follows the package version of `@flowstack-ui/brick`.

## Unreleased

### Fixed

- Inline Center no longer overrides surrounding-text baseline alignment.
  Inline Square/Circle keep their existing middle alignment; internal
  two-axis centering is unchanged.

### Added

- Added the shared documentation-page layout, six formatted source-paired
  examples, family props tables and TOC; retained qualification scenarios.

- Added Center for explicit block or inline two-axis centering.
- Added responsive Square and Circle components with required equal sizing,
  fixed flex participation, native-host composition, modular CSS, and Agent
  Knowledge guidance.
